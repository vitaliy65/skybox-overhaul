# Product Context

## Why This Project Exists
Ванильное небо плоское: один голубой цвет, жёсткий переход в туман у горизонта, одинаковые белые звёзды. Автор хочет «как в жизни», но не ломая стиль игры.

## How It Should Work
- Цвет неба и тумана плавно меняется с высотой солнца (палитра в `SkyPalette`), в дождь возвращается к ванильному.
- Ночью звёзды разных цветов и размеров мерцают; раз в несколько суток по небу ползёт комета.
- Горизонт мягко растворяется в цвете тумана, без линии.

## User Experience Goals
Узнаваемо ванильно (пиксельные квадраты, те же созвездия: тот же seed 10842), но красивее. Ничего резкого и «неонового».
Пользователь: говорит по-русски, любит краткость, просил «всегда задавай вопросы» (задавай по одному вопросу в конце ответа).
