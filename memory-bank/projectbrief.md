# Project Brief

## Project Name
Skybox Overhaul (`skybox-overhaul`, пакет `skybox.overhaul`), клиентский Fabric-мод для Minecraft **26.1**.

## Core Goal
Переосмыслить небо Minecraft: красивые разноцветные градиенты как в реальной жизни (день, золотой час, закат, сумерки, ночь), живые звёзды и редкие кометы, но при этом оставаться максимально «ванильным».

## Key Requirements
- Градиент неба зависит от высоты солнца; горизонт и земля (туман) стыкуются без шва.
- Никакой видимой «полосы»/линии на горизонте (см. progress.md, это главная нерешённая проблема).
- Звёзды: квадратные пиксельные, как в игре; у каждой свой размер, яркость, цвет и ритм мерцания; есть крупные яркие.
- Кометы с хвостом: редко, медленно ползут по небу.
- Минимум кода, без лишних зависимостей (принцип ponytail).

## Scope
В рамках: Overworld-подобные измерения (skybox не NONE и не END), клиентская часть, миксины + собственные пайплайны.
Вне рамок (пока): Nether/End, млечный путь, падающие звёзды (предлагались, пользователь выбрал только кометы), свои шейдеры.
Северное сияние уже есть (`client/aurora/`: столбы-лучи на сетке, ночью в холодных биомах), с v1.4.0 анимированное.
